# not-paid

**Not-Paid** es una librería moderna diseñada para ayudar a desarrolladores a indicar visualmente cuando una prueba, membresía, suscripción o servicio ha alcanzado su fecha límite de pago.
Permite mostrar banners, diálogos o mensajes dinámicos cuando el usuario está atrasado, integrándose fácilmente en cualquier aplicación web.

Este proyecto está inspirado y basado en el script original **[Not-Paid](https://github.com/kleampa/not-paid)** publicado en GitHub, el cual introdujo la idea de detectar expiraciones y mostrar alertas para motivar al usuario a completar un pago pendiente.
La librería Not-Paid expande ese concepto y lo moderniza, incorporando mejores prácticas, componentes reutilizables y soporte para frameworks actuales.

## Características principales

- 📅 Manejo completo de fecha de expiración (por días o fecha exacta).

- 🔔 Notificaciones visuales automáticas: banner, diálogo o pantalla completa.

- 💾 Persistencia mediante localStorage.

- 🎨 Temas personalizables y opciones de estilo.

- Web Components (compatible con cualquier proyecto).

- 🛡️ Protección contra intentos de ocultar o eliminar el componente.

### 🧱 Objetivo del Proyecto

Modernizar y extender el comportamiento del script original notpaid, creando una librería modular y flexible que pueda utilizarse en:

- SaaS / Portales de membresía

- Herramientas de prueba (trial mode)

- Sistemas internos que requieren pagos recurrentes
